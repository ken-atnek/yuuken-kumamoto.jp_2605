# 外部レビュー依頼テンプレート

## 依頼内容

このプロジェクトについて、実装済みのコードとmdを確認し、公開前レビューをしてください。

## 前提

- Next.js App Router
- TypeScript
- SCSS
- 静的書き出し `output: 'export'`
- `public/db` の JSON をクライアントで取得する運用
- 既存構成を優先し、大幅リファクタは前提にしない

## 確認してほしい範囲

- 画面崩れにつながるHTML / JSX構造
- SCSSの破綻やレスポンシブ上の懸念
- `public/db` 取得まわりの実装
- sitemap / robots / metadata のSEO設定
- 画像パス、alt、OGP画像
- 静的 export と矛盾する実装
- 保守時に事故りやすい命名や状態管理

## 優先してほしい観点

1. 画面が壊れる・ビルドできない問題
2. 公開後のSEOやインデックス制御に関わる問題
3. DB更新が即時反映されない問題
4. スマホ・タブレット・PCでの表示崩れ
5. 後から管理画面連携しにくくなる構造

## 出力形式

1. **致命的な問題**
2. **修正推奨**
3. **修正しなくてもよいが気になる点**
4. **mdと実装の矛盾**
5. **SEO上の懸念**
6. **総評**

## Codex側の作業記録ルール

レビュー結果を受けてCodex側で対応する場合は、`docs/review/REVIEW_YYYY-MM-DD.md` を作成または更新する。

レビューmdには冒頭に `進捗サマリー` を置き、以下のステータスで作業状況を見える化する。

- `✅ 対応済み`
- `⏳ 再確認待ち`
- `⚠️ 要確認`
- `⬜ 未対応`

各項目には、対象ファイル、対応内容、確認方法、残タスクを残す。

## 注意

- 一般論ではなく、このプロジェクトのファイル名・行番号をもとに指摘する
- 大幅な作り直しではなく、最小修正案を優先する
- 仕様mdと実装がズレている場合は、どちらを正にすべきかも提案する
