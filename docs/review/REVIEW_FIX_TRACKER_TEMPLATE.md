# レビュー修正トラッカー テンプレート

## ファイル作成ルール

外部レビュー指摘の対応状況を管理する場合は、このテンプレートを元に `docs/review/REVIEW_FIX_TRACKER_YYYY-MM-DD.md` を作成する。

## ステータス定義

- `⬜ 未対応`
- `⏳ 再確認待ち`
- `⚠️ 要確認`
- `✅ 対応済み`
- `対応不要`

## 管理テーブル

| ID      | 優先度 | 指摘元           | 指摘内容                    | 対象ページ/URL | 対象ファイル         | 対応方針      | ステータス | 備考 |
| ------- | ------ | ---------------- | --------------------------- | -------------- | -------------------- | ------------- | ---------- | ---- |
| REV-001 | 高     | 例: 外部レビュー | 例: sitemap に必要URLが不足 | `/works/`      | `src/app/sitemap.ts` | 必要URLを追加 | ⬜ 未対応  |      |

## 日付別レビューmd

プログラムチェック、公開前チェック、外部レビュー後の対応を行う場合は、必要に応じて `docs/review/REVIEW_YYYY-MM-DD.md` を作成または更新する。

日付別レビューmdの冒頭には `進捗サマリー` を置き、ユーザーが作業状況と残タスクを追えるようにする。
